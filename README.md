# BookBin - IT 340 Project

BookBin is a book search website. Users make an account, log in, and search for books using the Open Library API.

Konrad Sikorski - IT 340, Fall 2026

## Milestone 1: Front-End
- `frontend/index.html` - Home page
- `frontend/login.html` - Login page
- `frontend/register.html` - Register page
- `frontend/style.css` - Styles for all 3 pages

The pages are hosted with nginx on VM 1 (Front-End), running Ubuntu Server.

## AI Usage
I used Claude (an AI tool) to help generate the HTML and CSS for the Home, Login, and Register pages, based on the mockups from my project proposal. I went through the code to make sure I understand it and that it matches my design.
